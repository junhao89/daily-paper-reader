## 摘要
多智能体交互世界模型不仅应生成一致的观测结果，还应维护跨智能体持久存在且随视角演化更新的世界状态。现有自回归视频扩散框架将观测历史作为条件上下文传递，这使得在多智能体和多视角设置下难以维护共享状态。我们提出WorldWeaver（W²），一种流式多智能体视频扩散模型，该模型通过引入跨智能体世界状态寄存器来增强生成过程：这些可学习token可存储共享世界信息、追踪个体智能体状态，并在每个生成块后动态更新。我们利用涵盖个体智能体状态、包括俯视图在内的全局状态视图以及场景文本的监督信号来约束这些寄存器。我们进一步通过混合Transformer架构改进模型，该架构使用独立权重分别处理世界状态建模和视觉帧建模。在两个智能体的Minecraft视频生成任务上的大量实验表明，显式的世界状态建模提升了逻辑一致性和生成质量。

## Abstract
Multi-agent interactive world models should not only generate consistent observations, but also maintain world states that persist across agents and evolve across views. Existing autoregressive video diffusion pipelines carry forward observation history as conditioning context, which makes shared state difficult to maintain in multi-agent and multi-view settings. We present WorldWeaver (W^2), a streaming multi-agent video diffusion model that augments rollout with cross-agent world state registers: learnable tokens that store shared world information, track individual agent status, and are dynamically updated after each generated chunk. We ground these registers with supervision signals spanning individual agent status, global state views including bird's-eye views, and scene text. We further improve the architecture with a Mixture-of-Transformers design that uses separate weights for world state modeling and visual frame modeling. Extensive experiments in two-agent Minecraft video generation show that explicit world-state modeling improves logical consistency and generation quality.

## 1. 核心问题与整体含义（研究动机和背景）
- **问题**：多智能体交互世界模型在生成多个智能体的观测时，需要维护一个跨智能体、随视角演化的**共享世界状态**。然而，现有自回归视频扩散模型仅将过去帧作为条件上下文传递，缺乏对底层世界状态的显式建模；在多视角设置下，每个智能体只能看到局部2D投影，难以保证跨智能体的逻辑一致性和几何一致性。
- **背景**：流式视频扩散（如Diffusion Forcing、Self-Forcing）支持长时生成，但记忆仅存在于局部上下文窗口或KV缓存中，无法捕捉观测不到的物体状态变化。多智能体环境（如Minecraft双人交互）进一步放大了状态一致性问题。
- **整体含义**：主张**显式建模世界状态**，而非将其作为帧生成的副产品，从而提升多智能体视频生成的逻辑连贯性和质量。

## 2. 论文提出的方法论

### 核心思想
- 引入**世界状态寄存器（World State Registers, WSR）**：一组可学习的token，用于存储共享世界信息（全局布局、个体状态等），并在每个生成块后动态更新。寄存器具有**跨智能体持久性**和**动态可更新性**两个关键属性。

### 关键技术细节

#### 世界状态寄存器机制
- 寄存器表示为 \( r_i \in \mathbb{R}^{K \times d} \)，共 \(K\) 个token。
- 生成流程：每个时间步 \(i\)，模型先生成帧 \(x_i\)，然后基于前一寄存器 \(r_{i-1}\) 和当前帧更新出 \(r_i\)；下一帧 \(x_{i+1}\) 则条件于 \(r_i\) 和局部帧窗口。
- 注意力掩码：帧token与寄存器token交替排列（\([x_0, r_0, x_1, r_1, \dots]\)），寄存器attention关注局部帧窗口和前一个寄存器，实现因果的“状态-帧”交替。

#### 监督信号（辅助世界状态预测）
- **个体状态**：预测每个智能体的位置、速度、方向（MSE损失）。
- **全局俯视图（BEV）**：预测DINOv2特征（余弦相似度损失），使用固定相机拍摄的俯视图作为目标。
- **场景文本**：预测文本描述（交叉熵损失），使用Qwen2.5-VL生成标注，冻结Llama-3.2-1B作为监督模型。

#### 模型架构：Mixture-of-Transformers (MoT)
- 将寄存器token和帧token使用**独立权重（不同Transformer分支）**处理，但共享注意力机制。这避免了帧视觉建模与状态更新的参数竞争。
- 由两个分支组成：视觉分支处理帧token，状态分支处理寄存器token，初始化时状态分支从视觉分支复制。

#### 三阶段训练流程
1. **Stage 1（双向训练）**：在同步多智能体 clip 上训练双向注意力教师模型，保留单玩家预训练先验。
2. **Stage 2（因果训练）**：将教师转化为因果学生，加入世界状态寄存器和监督信号，使用Flow Matching损失。
3. **Stage 3（自强制训练）**：学生模型在自己的生成帧和寄存器上滚动，使用DMD风格分布匹配损失（L_sf）加上寄存器监督损失，解决训练-测试不匹配。

### 推理流程（Algorithm 1）
- 维护帧KV缓存（窗口大小W）和寄存器KV缓存。
- 对每个生成帧：初始化噪声，逐步去噪；去噪后更新KV缓存，并基于当前帧和旧寄存器生成新寄存器。
- 仅保留第一个寄存器 \(r_0\) 和最新寄存器 \(r_i\) 在缓存中。

## 3. 实验设计

### 数据集/场景
- **数据来源**：基于SolarisEngine模拟的Minecraft双智能体交互数据，约126小时同步双人视频（20fps，832×480）。
- **标注**：每个智能体的位置/速度/方向（从模拟器导出）；固定俯视图（全局视角）；场景文本（使用Qwen2.5-VL-72B按4帧块生成描述）。
- **任务**：给定第一帧和完整动作序列，生成剩余视频帧。

### 基准方法与评估指标
- **基准方法**：
  - **Frame concat**：将两玩家观测沿通道拼接（类似于Multiverse方法）。
  - **Solaris**：多智能体世界模型，使用双向跨玩家注意力（重新训练在相同数据上）。
- **评估指标**：
  - **VLM准确性**：用VLM（视觉语言模型）判断生成视频中世界关系是否正确（包括Movement, Grounding, Memory, Building, Consistency五个类别）。
  - **FID**：衡量视觉真实感。
  - **世界分数（World Score）**：VLM均值/FID均值×100，作为辅助排序指标。

## 6. 主要结论与发现
- **显式世界状态寄存器**比仅靠帧历史条件能显著提升多智能体视频的逻辑一致性（VLM准确度提高10-20个百分点）。
- **多信号组合监督**优于单一信号，其中场景文本单监督效果最强，三者组合最佳（世界分数105.1）。
- **MoT架构**在寄存器携带丰富语义信息时优于密集架构，分离参数避免了状态与帧建模的冲突。
- **半监督学习**有效：更多无标签数据加入可提高生成质量，表明世界状态可以通过少量标签锚定，扩展至标签匮乏场景。
- 三阶段训练（双向→因果→自强制）对于稳定长时滚动生成至关重要。

## 7. 优点
- **创新性**：首次将世界状态作为可学习寄存器显式纳入流式视频扩散框架，并利用多模态监督信号（状态、俯视图、文本）进行约束。
- **架构设计**：采用MoT分离状态和视觉分支，有效缓解参数竞争，提升训练稳定性。
- **训练策略**：结合自强制训练（Self-Forcing）与状态寄存器更新，缓解训练-测试漂移。
- **可解释性**：通过解码寄存器得到的个体状态、俯视图、文本，使得世界状态可检查和验证。
- **实验完整性**：进行了丰富的消融和架构分析，验证了各组件贡献。
