## 摘要
视觉-语言模型（VLM）智能体越来越多地使用工具在三维场景中执行操作，而不仅仅是描述它们。现有的三维基准测试主要针对文本响应或单目标操作进行评估，而忽略了智能体在完整的多目标三维场景中的操作能力。我们提出了SceneActBench，这是一个在统一的智能体-环境循环下，针对五项三维任务进行的视觉条件操作基准测试。给定PNG图像或采样的视频帧，以及（如果适用）提供的三维资产，智能体在三维环境中执行操作。我们针对每个最终输出，使用特定于任务的几何指标与隐藏的真实数据进行评估。SceneActBench由210个源实例构建的五项任务组成，产生了520个任务案例，包括配对的输入条件。每个任务通过一个固定的智能体循环运行，以保持比较的公平性。在十一种专有的VLM配置中，总体得分范围在38.6到50.2之间，没有一种配置能在所有任务中表现一致。我们进一步分析了失败发生的位置和方式。

## Abstract
Vision-language model (VLM) agents increasingly use tools to act on 3D scenes rather than only describe them. Existing 3D benchmarks score textual responses or single-object operations, leaving agent action on complete multi-object 3D scenes under evaluated. We present SceneActBench, a benchmark for visually conditioned action across five 3D tasks under a unified agent-environment loop. Given PNG images or sampled video frames and, where applicable, supplied 3D assets, an agent acts on a 3D environment. We evaluate each final output against hidden ground truth with task-specific geometric metrics. SceneActBench comprises five tasks built from 210 source instances, yielding 520 task cases including paired input conditions. Every task runs through one fixed agent loop to keep the comparison fair. Across eleven proprietary VLM configurations, Overall scores span 38.6-50.2, and none performs consistently well across tasks. We further analyse where and how failures manifest.

#### 2. 方法论
- **核心思想**：构建一个“可执行”（Executable）的基准。给定视觉证据（图像或视频帧），智能体必须在一个3D环境（Blender）中执行行动（通过代码），产生一个具体的3D输出（如场景布局、动画、相机位姿）。这个输出会与隐藏的真实3D场景进行几何上的精确比较，从而直接评估智能体的行动能力，而不仅仅是描述能力。
- **关键技术细节**：
    - **统一智能体-环境循环**：所有任务都使用相同的界面与Blender交互。该循环包含：
        1.  **检查（Inspect）**：通过MCP（模型上下文协议）工具查询场景和物体状态。
        2.  **行动（Act）**：执行Blender Python代码来修改场景（如移动物体、设置相机、创建关键帧动画）。
        3.  **渲染（Render）**：生成2D图像以视觉检查，并与参考图像对比。
        4.  **迭代（Revise）**：在预算步数内，根据视觉残差反复修正，直到满意或预算耗尽。
    - **任务设计**：基准包含5个任务，分别测试不同的3D能力：
        - **Layout（布局）**：测试“空间定位”能力。智能体根据房间图片，将标准化的3D家具模型摆放到正确的位置和朝向。度量指标为 ADD-S (Average Distance of Model Surfaces)。
        - **Camera（相机）**：测试“自我中心空间推理”能力。智能体根据一张固定场景的图片，推测拍摄此图片的相机6自由度位姿。度量指标为 PE (Position Error) 和 AE (Angular Error)。
        - **Articulated（铰链体）**：测试“运动学推理”能力。智能体观察一个铰链物体（如柜门）的开合视频，推断出运动部件的关节类型、轴和运动范围，并复现其运动。度量指标为 MPE (Maximum Part Error)。
        - **Reconstruction（重建）**：测试“形状想象”能力。智能体从多张房间图片出发，在空场景中“凭空”重建出每个家具的3D几何形状、位置和颜色。度量指标为 F@5%。
        - **Dynamic（动态）**：测试“动态推理”能力。智能体观看一个包含多个运动物体（如车辆、球）的视频，需要重建静态场景布局，并为每个运动物体创建正确的三维运动轨迹。度量指标为 MME (Maximum Mover Error) 和 LE (Layout Error)。
- **数据处理**：从3个公开数据集（3D-FRONT, S2O ACD, Kenney）中提取数据并进行标准化处理（匿名化ID、居中、去朝向），防止智能体通过物体本身的信息（如文件名）作弊，迫使其只能依赖视觉输入来理解场景。

#### 6. 主要结论与发现
- **整体性能低下**：所有模型在SceneActBench上的表现都不理想，最高得分仅为50.2（满分100），没有任何模型能得心应手地完成所有任务。
- **没有全能选手**：得分相近的模型（如48.7-50.2）在不同的任务上各有所长，没有哪个模型在所有任务上都有绝对优势。例如，GPT-5.4 High在三个任务上领先，但因在“动态”任务上表现极差而排名不高。
- **视觉输入并非越多越好**：提供更多视图（多视图布局）或更逼真的参考（逼真动态场景）并非对所有模型都有益，效果高度依赖于具体模型。
- **失败模式多样**：相似的最终得分可能掩盖了截然不同的失败模式。例如，Doubao在铰链体任务中几乎不移动任何部件（成功率低但错误少），而Claude则移动了很多部件但部分方向错误。这表明不同模型的能力短板各不相同。
