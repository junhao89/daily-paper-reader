## 摘要
为了在不同环境中有效运作，机器人不仅要精确执行操作任务，还要根据任务、物体和交互场景调整其动作的展开方式。我们探究这种执行层面的变化能否作为一种跨任务可复用的行为因子被学习。我们提出\textbf{MoMo}，一个两阶段模仿学习框架，包含一个时空动作标记器和一个以任务与连续运动模态条件为输入的行为克隆变换器。在六个真实机器人操作任务中，改变该条件会产生稳定、动态及中间态行为，这些行为能被人类评分者区分，并在关节速度、加速度及末端执行器接近俯仰角上有所差异。在仅以单一模态演示的任务上，MoMo能够迁移未见过的请求模态，同时基本保持任务成功率。综上，这些结果为对未见任务-模态组合的组成式泛化提供了证据，并表明运动模态可跨任务复用，以控制操作技能的执行方式。

## Abstract
To operate effectively across diverse contexts, robots must not only perform manipulation tasks accurately but also adapt how their actions unfold to the task, object, and interaction setting. We ask whether this execution-level variation can be learned as a reusable behavioral factor shared across tasks. We present \textbf{MoMo}, a two-stage imitation-learning framework consisting of a spatiotemporal action tokenizer and a behavior-cloning transformer that takes task and a continuous motion-mode condition as inputs. Across six real-robot manipulation tasks, varying this condition produces steady, dynamic, and intermediate behaviors that human raters can distinguish and that differ in joint speed, acceleration, and end-effector approach pitch. On tasks demonstrated in only one mode, MoMo transfers the unseen requested mode while largely preserving task success. Together, these results provide evidence of compositional generalization to unseen task--mode combinations and show that motion mode can be reused across tasks to control how a manipulation skill is performed.

## 1. 论文的核心问题与整体含义

- **研究动机**：机器人要在不同任务与交互场景中有效运作，不仅需要精确完成操作，还需能调整"行为展开方式"（如节奏、平滑度、加速度、末端姿态等）。现有模仿学习方法通常把行为风格与任务绑定学习，导致一种行为要迁移到新任务时需重新采集该任务的对应风格演示，行为本身无法作为可复用的因子跨任务传递。
- **核心研究问题**：运动模态（motion mode）——一种与任务无关的行为调制因子——能否在学习的动作分词空间中实现"表示、控制、跨任务复用"？即：能否实现未见任务–模态组合的**组合式泛化**？
- **整体含义**：该论文提出将动作执行中的"任务相关结构"与"可复用的行为变化"分离，使机器人操作策略可以在推理时单独调节任务（做什么）和运动模态（怎么做），为构建可交互、可调节的机器人操作策略提供了新范式。

## 2. 论文提出的方法论

- **核心思想**：动作可以分解为互补的**空间流**与**时间流**。空间流强调路径几何、接触、目标等任务相关结构；时间流强调步频、加速度、平滑度等运动模态相关结构。通过两个独立 RVQ（残差向量量化）码本并行编码，再融合解码，即可在离散动作记号空间中实现任务与模态的分离与重组。
- **MoMo 整体架构**：两阶段模仿学习框架。
  - **Stage 1（时空动作分词器）**：
    - **空间编码器**：1D 卷积栈直接处理原始联合空间轨迹 a ∈ R^100×7，下采样到 K=20 个时间位置，捕捉路径几何与接触结构。
    - **时间编码器**：计算联合增量 Δq，对其做 DCT 变换保留每关节前 16 个低频系数，经 2 层 MLP 投射到时间对齐的潜变量，强调速度/加速度等动力学信息。
    - **两路 RVQ 栈**：空间码本 Lsp=4 层（尺寸 [64,512,512,512]，首个码本作为内容瓶颈）；时间码本 Lte=4 层（每层 256）。
    - **融合与解码**：两路量化流拼接，经融合 MLP（LayerNorm+GELU）与 1D 上采样解码器重建动作块。
    - **训练目标**（7 项损失）：L1 重建损失、DCT 预测损失、同任务异模态的交换损失（swap-task/swap-mode，分别约束路径与频率内容）、时间码上的残差对比损失、空间潜变量上的对抗互信息惩罚、以及标准承诺损失。总体使空间流与时间流互补、可分离。
  - **Stage 2（行为克隆 Transformer）**：
    - 冻结 Stage 1 所有权重，训练一个 Transformer 编码器，接收前视与腕部相机 ResNet-34 特征、本体感觉、任务标识符嵌入，以及连续运动模态标量 s ∈ [0,1]。
    - 解码器为每个码本层配备一个分类头，外加一个连续偏移头以补偿量化误差。
    - 训练损失为各码本级交叉熵 + 偏移头 L1 损失。
- **推理过程**：输入当前观测、任务标识符与用户指定 s，取 argmax 获得离散索引，查表融合解码得到动作块，并使用 ACT 的时域聚合策略稳定执行。

## 3. 实验设计

- **硬件与环境**：
  - Interbotix X-Series 硬件，单臂 ALOHA 主从配置（WidowX-250 引导臂 + ViperX-300 6-DOF 跟随臂）。
  - 两台 480×640 相机（顶部固定相机 + 腕部相机），采集/执行频率 50 Hz，动作块 T=100（覆盖 2 秒）。
- **任务与数据集**：
  - 六个桌面操作任务，目标物从准备区移至目标区：
    - **双模态任务（各 60 条演示，Mode A/B 各 30）**：pick（拾取）、pour（倾倒）、look（朝向物体）、avoid（避让朝向）。
    - **单模态任务（每个仅用一种模态演示）**：highfive（接近并触碰人手，仅 Mode A）、push（推动物品，仅 Mode B）。
  - 初始物体位置和目标位置固定（±5 cm 内），每条轨迹从固定默认姿态开始，持续 16–20 秒。
  - 数据以 Robomimic HDF5 格式存储，训练时以步长 10 子采样预堆叠块。
- **评估协议**：
  - 每任务 × 每 s 值（0.1/0.5/0.9）滚转 N=20 次，给定 ±5 cm 初始偏移；记录关节轨迹、相机流、预测的时空码索引。
  - 三个客观运动动力学指标：关节速度、关节加速度、末端执行器接近俯仰角（由正运动学计算）。
  - 主观评估：3 名人类专家对每个滚转视频评分（风格一致性 0–10；任务完成度 0–10），对请求 s 与是否为转移单元均设盲。
- **对比方法**：论文**未与** BeT、VQ-BeT、FAST 或扩散策略等基线进行正式量化对比，主要采用自身内部条件对比（三种 s 值、训练任务 vs 转移任务）。

## 6. 论文的主要结论与发现

- **运动模态是可复用的行为因子**：在 4 个训练任务上，三种 s 值产生了模式间差异（Mode A 慢、稳、俯仰角更深；Mode B 快、动态、变化更多），中间值介于两者之间，且 Spearman 相关均强显著（p<10⁻⁶）。
- **组合式泛化成立但幅度有限**：
  - push（原仅 Mode B）在 Mode A 下速度与加速度向训练任务的 Mode A 区间移动，接近俯仰角下倾，但接触阶段成功率下降。
  - highfive（原仅 Mode A）在 Mode B 下动力学指标变化较弱，但人类评分者仍能正确感知其"动态"风格，说明标量指标未完全捕获行为变化。
- **潜空间组织符合任务/模态分离**：空间码按任务聚类、对模态不敏感；时间码按模态形成带、跨任务重叠。转移任务上，空间码保持在原任务簇，时间码向请求模态区域移动。
- **人类感知一致**：所有任务（含两个转移单元）的风格评分均随 s 单调变化，任务完成度几乎全部保持天花板水平（唯 push 在 Mode A 下例外），表明运动模态保留了共享的行为语义。

## 7. 优点

- **架构先验清晰**：利用"绝对关节轨迹→空间几何"、"联合增量 DCT→时间动力学"这一结构先验，将任务与模态在表征层面自然分离。
- **组合式泛化能力**：在未见任务-模态对上仅通过改变连续标量即可实现行为迁移，无需重新采集演示或微调，展示了一定程度的零样本行为控制。
- **多维度验证体系**：客观动力学指标、人类双盲评分、潜空间 PCA 三者相互印证，且人类评分能捕获客观指标遗漏的细微行为差异。
- **模块化设计与推理时可控性**：Stage 1 分词器冻结后作为稳定接口，Stage 2 仅需学习离散码上的行为克隆；推理时任务标识符与模态标量可独立调节，支持运行中切换。这与高层 LLM 策略结合的实际部署路径较清晰。
- **方法迁移性**：吸收了 VQ-BeT 的 RVQ 分词与 FAST 的 DCT 特征思路，并引入动画领域对比解耦思想（VQ-Style），交叉领域迁移较有启发性。

## 8. 不足与局限

- **实验覆盖有限**：单一机器人硬件（Interbotix）、六种桌面任务、物体位置仅 ±5 cm 扰动，未涉及物体位姿大变、人机共融复杂动态场景或不同夹具类别。
- **缺乏正式基线对比**：未与行为分词基线（BeT/VQ-BeT/FAST）、连续动作基线（ACT/扩散策略）或风格迁移方法进行量化对比，方法的效果增益因而缺乏参照系。
- **无消融实验**：未单独验证空间/时间分支、各损失项（交换损失、对比损失、MI 惩罚）对分解效果的贡献，无法排除某些设计冗余。
- **部分分离的固有局限**：论文承认运动模态存在空间相关联（如接近俯仰角），空间流会吸收部分模态信息，限制了转移幅度（highfive 的短距离路径限制了 Mode B 下的表达速度；push 在 Mode A 下接触可靠性下降）。
- **客观指标不完整**：速度/加速度标量未充分刻画行为变化，而人类感知能区分出更多维度（平滑度、犹豫、抓手的编排），说明现有指标存在测量盲区。
- **模态定义简化**：仅两个原型+一维标量，真实场景中的模态变化可能更高维（情绪状态、指令语气、用户偏好等），一维条件在实际部署中表达能力有限。
- **人类评估规模小**：3 名专家而非普通用户，且未报告评分者间信度（inter-rater reliability）；对"风格一致性"的评分标准未明确定义。
