## 摘要
许多最新的机器人策略尝试通过使用大型预训练视觉-语言模型（VLM）作为动作骨干来增强控制能力。我们提出了WorldDiT，一种统一的扩散Transformer架构，将动作生成与视觉世界建模相结合，在无需大型预训练VLM动作骨干的情况下实现了强劲性能。在训练过程中，一个单一的扩散Transformer生成连续的动作块，并从未来相机帧中预测归一化的RGB图像块目标。在四个LIBERO仿真套件上，WorldDiT位于所报告的总模型参数与平均成功率之间的帕累托前沿上，这些结果涵盖了所有报告四个套件结果的方法。这些工作为未来的扩展研究提供了一个强大的、参数低于十亿级别的基线模型。

## Abstract
Many recent robot policies pursue stronger control by using large pretrained vision-language models (VLMs) as the action backbone. We introduce WorldDiT, a unified diffusion transformer architecture that couples action generation with visual world modeling and achieves strong performance without a large pretrained VLM action backbone. During training, a single diffusion transformer generates continuous action chunks and predicts normalized RGB patch targets from future camera frames. Across four LIBERO simulation suites, WorldDiT lies on the reported Pareto frontier for total model parameters and mean success among methods reporting all four suites. These results provide a strong sub-billion-parameter baseline for future scaling studies.

### 一、核心问题与研究动机

- **核心问题**：机器人策略能否在不依赖大型预训练视觉-语言模型（VLM）作为动作骨干的情况下，仍获得强控制性能？
- **研究背景**：现有VLA（Vision-Language-Action）策略的普遍范式是“大型预训练VLM + 动作生成”，这种模式带来了广泛感知和语言理解能力，但存在两大弊端：
  1. 模型参数量可达数十亿，部署成本极高；
  2. 规模与架构的贡献难以分离——强控制力究竟来自动作设计、预训练骨干还是两者结合，难以判定。
- **动机**：是否需要一种无需大型预训练VLM骨干、参数量在十亿以下的统一扩散架构，既能生成动作，又能进行视觉世界建模，从而为后续扩展研究提供清晰、干净的基线。


### 二、方法论

#### 1. 核心思想

- WorldDiT 提出**单一共享扩散Transformer骨干**，同时完成两类生成任务：
  1. 连续**动作块**生成（用于控制）；
  2. 未来相机帧的归一化**RGB patch**预测（用于世界建模）。
- 关键设计在于：**RGB patch预测仅在训练时提供辅助监督，推理时被排除在图外**，不增加推理开销。

#### 2. 技术细节

- **输入观测**：使用冻结的 MAE 图像编码器（视觉）、冻结的 CLIP 文本编码器（语言），以及可训练的机器人状态编码器，将多模态输入投影为统一 token 空间。
- **动作与目标格式**：
  - 上下文长度：C = 3 步已观测状态；
  - 动作块：H = 7 步连续动作，输出维度 a ∈ ℝ⁷ˣ⁷；
  - 未来视觉目标：从主相机和腕部相机各取 64 个 patch，共 128 个 768 维归一化 RGB patch token，目标帧位于当前步之后的第 H 步。
- **训练目标**：采用 Flow Matching 框架，损失为加权和：

  \[
  \mathcal{L}_{total} = w_{action} \mathcal{L}^{action}_{flow} + w_{rgb} \mathcal{L}^{rgb}_{flow}
  \]

  其中权重分别为 \( w_{action} = 0.1 \)、\( w_{rgb} = 0.001 \)。模型从高斯噪声出发，学习沿直线路径流到干净目标的“速度场”。

- **推理流程**：
  1. 从高斯噪声初始化动作 token；
  2. 用 20 步 Euler 积分求解学到的速度场，得到预测动作块；
  3. 执行前 3 个动作，滑动上下文窗口，重新规划（滚动时域控制）；
  4. 预测时使用动作集成（temporal ensembling）提高稳定性。

### 六、主要结论与发现

1. **强性能无需大型 VLM 骨干**：WorldDiT 以 3.99 亿总参数（其中仅 1.35 亿可训练参数）在 LIBERO 四个套件上取得 98.0% / 97.0% / 92.8% / 91.8% 的成功率，平均 **94.9%**。
2. **帕累托前沿位置关键**：在所有报告四套件平均成功率的方法中，任何比 WorldDiT 成功率更高的方法都使用了更多总参数；任何参数量与它相当或更小的方法成功率都不如它。因此 WorldDiT 落在总参数量-平均成功率的帕累托前沿上。
3. **统一世界-动作建模范式可行**：动作生成与视觉世界预测可以在单一扩散 Transformer 内联合训练，且拥有仅动作的推理路径，这为将世界模型和策略统一为紧凑、可扩展基础提供了实证支持。
4. **Sub-billion 基线价值**：为未来研究提供了清晰的参数量低于十亿的基线，有利于后续扩展研究（更大模型、更多数据、更强泛化）。


### 七、优点与亮点

- **架构简洁统一**：不用大型预训练 VLM 作骨干，单一 DiT 同时承担动作生成与世界建模，架构纯净、贡献分离度高。
- **推理零额外成本**：视觉预测目标只在训练时起作用，推理时完全剔除，不牺牲部署效率。
- **参数量高效**：3.99 亿总参数 / 1.35 亿可训练参数，在性能相近的模型中是最轻量的方案之一。
- **帕累托前沿视角新颖**：不同于单纯刷分，作者从“参数量-性能”的权衡视角切入，为领域提供了更实际参考价值的视角。
- **结果透明**：作者主动声明数据聚合方式、held-out 局限以及对比协议的瑕疵，具备良好的科学诚信。


### 八、不足与局限性

- **评估偏差风险**：报告的 94.9% 中包含用于选择的 300/500 episodes，非完全独立的测试集，不能作为无偏估计。
