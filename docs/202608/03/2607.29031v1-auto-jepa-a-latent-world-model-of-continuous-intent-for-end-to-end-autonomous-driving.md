## 摘要
现有的自动驾驶世界模型通常执行未来视频、占用状态、BEV表示或智能体运动的密集预测。我们认为规划不需要重建完整的未来世界，而只需关注影响未来自车行为的场景特征。基于这一观点，我们提出Auto-JEPA，一种面向动作的潜在世界模型，通过联合嵌入预测学习连续的驾驶意图。给定视觉观测、自车运动历史以及导航指令，Auto-JEPA预测与未来自车轨迹的潜在表示对齐的意图嵌入。预测的意图从固定的轨迹记忆中检索可执行轨迹，然后由场景条件候选选择模块进行排序。Auto-JEPA保持视觉编码器冻结，不需要显式的感知标注，也不使用学习得到的轨迹生成器。通过仅优化用于轨迹表示、意图预测和候选选择的任务特定模块，Auto-JEPA在NAVSIM v1上达到91.3 PDMS，在NAVSIM v2上达到89.1 EPDMS。语义遮挡实验表明，遮挡动态智能体区域引起的平均意图变化是等面积随机遮挡的2.97倍。此外，遮挡影响未来驾驶的车辆会显著改变预测的意图和选择的轨迹，而遮挡无影响的车辆时两者基本不变。这些结果表明，未来意图预测鼓励模型关注与规划相关的视觉特征，并支持无需密集未来世界建模的高质量规划。

## Abstract
Existing autonomous-driving world models typically perform dense prediction of future videos, occupancy states, BEV representations, or agent motion. We argue that planning need not reconstruct the complete future world, but only focus on scene features that affect future ego action. Based on this perspective, we propose Auto-JEPA, an action-oriented latent world model that learns continuous future driving intent through joint-embedding prediction. Given visual observations, egomotion history, and navigation commands, Auto-JEPA predicts an intent embedding aligned with the latent representation of the future ego trajectory. The predicted intent retrieves executable trajectories from a fixed trajectory memory, which are then ranked by a scene-conditioned candidate selection module. Auto-JEPA keeps the visual encoder frozen, requires no explicit perception annotations, and uses no learned trajectory generator. By optimizing only task-specific modules for trajectory representation, intent prediction, and candidate selection, Auto-JEPA achieves 91.3 PDMS on NAVSIM v1 and 89.1 EPDMS on NAVSIM v2. Semantic occlusion experiments show that masking dynamic-agent regions induces an average intent change 2.97x that of equal-area random masking. Moreover, occluding vehicles that affect future driving substantially changes the predicted intent and selected trajectory, whereas both remain essentially unchanged when non-influential vehicles are occluded. These results show that future-intent prediction encourages the model to focus on planning-relevant visual features and supports high-quality planning without dense future-world modeling.

## 二、方法论：核心思想、技术细节与算法流程

### 2.1 整体框架

Auto-JEPA是一个**面向动作（action-oriented）的潜在世界模型**，其核心流程为：

```
视觉观测 + 自车运动历史 + 导航命令 → 预测未来意图嵌入 → 从固定轨迹记忆检索→ 场景条件评分与可行驶区域门控 → 输出最终轨迹
```

- 输入：前视摄像头4帧图像（256×256） + 4个历史自车位置 + 路线命令
- 输出：8个未来轨迹点（覆盖4秒规划时域，0.5秒间隔）

### 2.2 核心思想：以"未来轨迹隐空间"作为预测目标

**未来自车运动意图表示（Driving Intent）：**

每条未来自车轨迹表示为8个二维路径点：$Y = [(x_1, y_1), ..., (x_8, y_8)] \in \mathbb{R}^{8\times2}$

**两阶段训练：**

**阶段一：轨迹隐空间预训练（Trajectory Latent-Space Pretraining）**
- 训练一个轨迹自编码器：编码器 $E_{traj}$ 将未来轨迹映射为8个1024维潜在token（$Z^+ = E_{traj}(Y)$），解码器 $D_{traj}$ 重建轨迹
- 重建目标包含：路径点坐标损失（$L_{xy}$）、终点损失（$L_{end}$）、速度损失（$L_{vel}$）、加速度损失（$L_{acc}$）
- 预训练完成后，**丢弃解码器，冻结轨迹编码器**，使其定义预测目标空间，并为轨迹记忆中的所有轨迹编码

**阶段二：视觉意图预测（Visual Intent Prediction）**
- 冻结的V-JEPA 2视觉编码器提取视觉token
- 历史编码器（$E_{hist}$）和命令编码器（$E_{cmd}$）分别编码自车运动历史和导航命令
- 24层Transformer预测器（隐藏维度1024、16个注意力头）融合视觉、运动、命令特征与8个可学习未来查询token，输出预测意图 $\hat{Z}$

### 2.3 联合嵌入训练目标（JEPA Loss）

对比直接监督路径点坐标（ADE/FDE），Auto-JEPA在冻结的轨迹隐空间中优化以下三个目标：

| 损失项 | 公式/描述 |
|--------|-----------|
| **特征对齐损失** $L_{feat}$ | 对预测和目标潜向量归一化后应用Smooth L1损失 |
| **逐token余弦对齐** $L_{cos}$ | 最小化8个时间位置上预测与目标token的余弦距离 |
| **批量InfoNCE** $L_{NCE}$ | 将完整潜序列展平归一化，以本场景目标为正样本，其他场景目标为负样本，温度τ=0.07；训练时跨GPU聚合负样本 |

**总目标：** $L_{intent} = 0.1L_{feat} + 2.0L_{cos} + L_{NCE}$

这些目标同时实现**局部特征对齐**、**时间token语义对齐**和**跨场景判别性**，使预测的潜向量适合轨迹检索。

### 2.4 推理：非参数轨迹检索 + 场景条件选择

**轨迹记忆构建：**
- 仅使用NAVSIM训练集中的**地面真值轨迹**（N=110,335条），由冻结的同一轨迹编码器编码为 $Z_n = E_{traj}(Y_n)$
- 记忆中的每条记录保留潜向量和原始路径点坐标，直接提供候选几何

**检索流程：**
- 将预测意图展平并L2归一化，与记忆中的潜向量计算**扁平余弦相似度** $r_n = q^\top m_n$
- 检索Top-K（K=300）最相似轨迹

**场景条件评分（Scene-Conditioned Scorer）：**
- 从CLOVER轨迹评分器初始化，仅在Auto-JEPA检索到的地面真值候选上重新优化
- 训练监督包括：碰撞、可行驶区域、时距碰撞（TTC）、舒适度、自车进度等，加上场景内排序目标

**可行驶区域可行性门控（DAC Gate）：**
- 独立训练的二元分类器预测候选轨迹发生DAC（可行驶区域合规）失败的概率
- 推理时以τ=0.2为阈值，过滤可能违反可行驶区域约束的候选
- 若所有候选均被过滤，则回退到无门控的效用排序

**最终选择：** $k^* = \arg\max_{k:m_k=1} s_k$，即通过门控的候选中效用得分最高者。

### 2.5 设计特点总结

- ✅ 视觉编码器完全冻结（V-JEPA 2）
- ✅ 无显式感知标注（无物体框、占用、语义地图、周围智能体运动标注）
- ✅ 无学习式轨迹生成器（非参数记忆检索）
- ✅ 各模块职责分离：意图预测决定"什么样的未来动作是合适的"，记忆提供轨迹几何，评分器估计场景级驾驶质量，门控减少可行驶区域违规

## 六、主要结论与发现

1. **未来意图预测足以支持高质量规划**：Auto-JEPA无需密集未来重建即可在NAVSIM v1/v2上达到领先水平（91.3 PDMS、89.1 EPDMS）。

2. **模型选择性关注规划相关特征**：遮挡动态智能体区域引起的平均意图变化（0.080）是等面积随机遮挡（0.027）的**2.97倍**，且动态智能体干预在71.1%的样本中产生更大响应。

3. **单车辆遮挡的差异化响应**：
   - 遮挡"有交互的前车"→ 意图和轨迹显著变化
   - 遮挡"无交互的邻车"→ 意图和轨迹基本不变
   - 这种选择性在没有任何物体框、智能体身份、交互标签或周围智能体运动标注的条件下自发涌现

4. **各模块职责分离有效**：
   - 意图预测提供检索查询（将PDMS从52.6提升至87.6）
   - 场景评分器贡献+3.7 PDMS
   - 可行驶区域门控提升DAC 0.4个百分点（从97.9至98.3）

5. **候选池大小趋于饱和**：K从1增至200带来3.5 PDMS的提升，但从200增至300仅增加0.2，表明在当前记忆质量和意图预测精度下，单纯扩大候选池的边际收益递减。

## 八、不足与局限

### 8.1 方法层面的局限

1. **记忆覆盖率限制**：检索式规划被固定轨迹记忆的覆盖范围所限制。如果某个场景不存在合适的机动轨迹在记忆池中，评分器和门控都无法"创造"一个。

2. **候选池饱和效应**：K从200到300边际收益仅0.2 PDMS，说明在预测器-记忆组合下性能趋于饱和。论文建议的扩展方向是**意图条件轨迹生成或局部精化**。

3. **评分器校准风险**：有效候选可能获得不准确的低场景分数，门控可能拒绝合法的边界轨迹或保留违规划线的候选。all-filtered回退策略保证非空输出，但无法修复错误的排序。

4. **无场景级预测能力**：当前设计是"面向动作"的，无法提供交互式仿真、反事实环境生成等应用所需的周围智能体状态预测。

### 8.2 实验层面的局限

1. **单次运行的确定性评估**：所有结论基于单一种子（seed=42）的单个checkpoint，未报告多运行平均和标准差；对于随机性较高的深度学习系统，结果稳健性存疑。

2. **训练时长与算力报告不完整**：未说明端到端训练总时长、GPU小时数或能耗。

3. **NAVSIM局限**：NAVSIM是非反应式基准（非反应式模拟器），无法完全反映闭环交互场景中的真实驾驶表现；v2的TL指标在原始评估中仅为97.2（更新后为99.7），说明评估协议对结果有显著影响。

4. **对比公平性**：v2对比方法均为source-reported，评估设置不完全一致（如不同骨干网络、不同传感器配置），Auto-JEPA在LC（车道保持，84.0）和EC（扩展舒适度，75.4）上低于部分方法。

### 8.3 应用层面的限制

- 当前仅使用前视单目摄像头，**未利用环视相机、LiDAR或HD地图**，在多传感器融合成为主流趋势的背景下，其适用场景有限。
- 模型对**罕见边缘场景**（如极端天气、非常规交通参与物）的鲁棒性未在实验中覆盖。
- 记忆检索方式在**大规模部署**时需要额外的工程处理（如高效的ANN检索索引），论文中未讨论推理时延和计算效率。

## 总结

Auto-JEPA提出了一种全新的规划导向世界模型范式：**以连续驾驶意图（未来自车轨迹的隐表示）为预测目标，通过联合嵌入预测实现传感器到轨迹的端到端规划**。其核心洞见在于"规划不需要重建完整未来世界"——这一论断通过充分的消融和语义遮挡实验得到了有力验证。尽管在实验稳健性（单次运行）、记忆覆盖率、基准非反应性等方面存在局限，Auto-JEPA为自动驾驶世界模型的研究提供了一个"少即是多"的有力范例，也为后续工作在意图条件轨迹生成、更大规模记忆与更稳健评分校准等方向开辟了明确的改进路径。
