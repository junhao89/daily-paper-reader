## 摘要
世界动作模型（WAMs）联合预测未来的观测和动作，但它们的迭代去噪和闭环执行使得高效部署成本高昂。现有的训练后量化（PTQ）方法不适合WAMs，因为它们依赖于开环目标、同构模型假设以及不反映部署的校准分布。我们提出了QuantWAMs，一个PTQ框架，使量化决策与由模型结构、展开分布和任务目标定义的校准上下文对齐。QuantWAMs引入了三种策略：共享基异常值校准，它仅跨坐标兼容模块汇集激活证据；共同训练目标显著性，它从联合视频-动作梯度计算经验Fisher分数，并在校准稳定的层粒度上分配权重精度；以及固定干预展开审计，它使用可达的闭环状态修订去噪步骤保护计划，而不改变精度预算。我们在Fast-WAM和LingBot-VA上评估了QuantWAMs，涵盖RoboTwin 2.0、LIBERO以及使用AgiBot G2的真实机器人操作。在W4A4主导的设置下，报告的模拟平均值与FP16相差0.2-0.7个百分点。真实机器人试验进一步建立了三个操作任务的部署可行性。对于目标的视频和动作块，QuantWAMs将峰值权重和激活内存降低到FP16的约29%，并提供1.4-1.6倍的块级加速。

## Abstract
World Action Models (WAMs) jointly predict future observations and actions, but their iterative denoising and closed-loop execution make efficient deployment costly. Existing post-training quantization (PTQ) methods are poorly suited to WAMs because they rely on open-loop objectives, homogeneous model assumptions, and calibration distributions that do not reflect deployment. We present QuantWAMs, a PTQ framework that aligns quantization decisions with the calibration context defined by model structure, rollout distribution, and task objective. QuantWAMs introduces three strategies: shared-basis outlier calibration, which pools activation evidence only across coordinate-compatible modules; co-training-objective saliency, which computes empirical-Fisher scores from the joint video--action gradient and assigns weight precision at a calibration-stable layer granularity; and fixed-intervention rollout auditing, which revises denoising-step protection schedules using reachable closed-loop states without changing the precision budget. We evaluate QuantWAMs on Fast-WAM and LingBot-VA across RoboTwin 2.0, LIBERO, and real-robot manipulation with an AgiBot G2. Under a W4A4-dominant setting, the reported simulation means differ from FP16 by 0.2--0.7 percentage points. Real-robot trials further establish deployment feasibility on three manipulation tasks. For the targeted video and action blocks, QuantWAMs reduces peak weight-and-activation memory to about 29\% of FP16 and provides 1.4--1.6$\times$ block-level speedups.

## 一、论文的核心问题与整体含义（研究动机与背景）

- **背景**：世界动作模型（World Action Models, WAMs）将视频扩散世界模型与扩散动作专家相结合，联合预测未来观测与实现这些观测所需的动作，是通用机器人操作的一种有前景的范式。但其每个控制周期都需要迭代去噪，且以闭环方式执行——每一次生成的动作都会改变后续预测所依赖的观测，导致部署成本高昂。
- **核心问题**：训练后量化（PTQ）是通向真实机器人部署的自然路径，但现有 PTQ 方法对 WAMs 并不适用，原因在于它们依赖两个失效假设：
  1. **开环目标**：以困惑度或单帧图像重建等开环指标评分，每次前向独立打分，忽略了早期量化误差通过闭环交互传播到后续状态的问题。
  2. **同质模型假设**：假设模型是单一同构 Transformer，而 WAMs 将计算分布在耦合的多条通路上（双流 Mixture-of-Transformers 或共享扩散骨干）。
- **核心洞察**：每个 PTQ 决策都是在部署前基于一种"校准上下文"（calibration context）做出的有限样本估计，该上下文由三方面决定：证据汇集的**范围 G**、度量所依据的**状态分布 D**、评分的**目标函数 L**。任何维度不匹配都会导致精度分配失误——结构不匹配会跨无共同坐标系的成员汇集证据，分布不匹配会在闭环不可达的状态上刻画敏感性而产生"幻影去噪峰值"，目标不匹配会忽略联合视频–动作梯度中的逐坐标交互项。

## 二、方法论：QuantWAMs 的三大策略

QuantWAMs 将三个策略统一在"按部署时可支持的粒度审视每个决策"的原则之下：

### 1. 共享基异常值校准（Shared-Basis Outlier Calibration）

- **目标**：决定激活异常值的 Top-K 掩码（保留 K=⌊ρd⌋ 个高精度输入通道）应在哪些模块/上下文之间共享。保留 Atom 的混合精度通道卸载原语和"平方和"通道统计量，但研究其静态掩码的共享范围。
- **预处理**：每个上下文的激活经过 `Ã⁽ⁿ⁾ᵢ = (A⁽ⁿ⁾ᵢ R)S⁻¹ᵢ`，其中 Hadamard 旋转 R 在同一可容许组内共享，Sᵢ 是上下文特定的对角平滑矩阵。
- **坐标可容许性（Coordinate Admissibility）**：仅当字面索引在成员间表示同一量化器输入坐标时才能共享（如 Aᵢ = PᵢZ，共享公共有序基）。Fast-WAM 中共享 value 通路可对齐配对的输出投影，但专家私有的残差流不允许跨专家共享 Q/K/V；LingBot-VA 中不同模态复用同一物理 Linear 的输入列，因此跨模态共享是容许的。
- **核心理论（Proposition 1, 池化交叉点）**：将每个通道统计量建模为 `zᵢ⁽ⁿ⁾(c) = μ_g(c) + τ_cηᵢ(c) + σ_cξᵢ⁽ⁿ⁾(c)`，其中 τ² 为跨成员异质性，σ² 为成员内采样方差。池化降低风险的充要条件是：

  **N < N⋆_c = σ²_c / τ²_c**（τ²>0 时）；若 τ²=0，则池化对任意有限 N 均占优。

  有效样本量 `Neff = mN / [1 + (m−1)Nτ²/σ²]`。此外还给出了掩码恢复概率界（式 8）：当 βᵢ < Δᵢ/2 且池化误差为通道级 sub-Gaussian 时，池化掩码偏离成员最优掩码的概率有指数界。
- **筛选规则**：仅在满足 N_cal < N̂⋆_g 且引导（bootstrap）掩码稳定性的坐标可容许组内进行池化；使用 32 条标定轨迹的轨迹级 bootstrap 重采样评估稳定性（不设第二次拟合划分）。

### 2. 共同训练目标显著性（Co-Training-Objective Saliency）

- **目标**：决定逐层权重精度分配（哪些层升级到 W8）。核心思想是权重显著性必须用 WAM 预训练时的**联合视频–动作共同训练目标** `ℓ_co = λ_vℓ_v + λ_aℓ_a` 来度量，而非单一流目标。
- **关键公式**：联合 Fisher 矩阵与后验融合（post-hoc fusion）的差异为：

  `G_joint_L = λ²_v Gᵛ_L + λ²_a Gᵃ_L + λ_vλ_a(Ξ_L + Ξ⊤_L)`

  而对角近似下保留的差异项为 `diag(G_joint_L − G_fusion_L) = 2λ_vλ_a E[g_{v,L} ⊙ g_{a,L}]`——融合方法在叉积前丢失了逐坐标的跨流对齐信息。
- **位宽分配**：以 Kronecker 因子化的经验 Fisher 近似计算位宽特定失真 `D_L(b) = ½ tr[G_L ε⁽ᵇ⁾_L Σ_L (ε⁽ᵇ⁾_L)⊤]`，升级收益 `B_L = D_L(b_lo) − D_L(b_hi)`，通过背包问题 `max Σ z_L B_L, s.t. Σ z_L c_L ≤ B` 选择升级对象（实现中 c_L=1、B=⌊0.2|L|⌋，即按数量升级前 20% 的候选 Linear 层）。
- **粒度选择**：元素级排名在有限标定数据下不稳定，因此**精度分配用层总计**，列总计仅作为 GPTQ 内部的排序启发式，元素级不作为分配单元。

### 3. 固定干预滚动审计（Fixed-Intervention Real-Rollout Auditing）

- **动机**：扩散 PTQ 需要时间步感知校准，但 WAM 的失配更强——早期调用产生的动作会改变之后的观测。合成/开环输入构建的敏感性画像可能在"错误的状态"上度量了正确的局部分歧。
- **三种画像对比**：
  - `S_syn(t)`：合成分布，遗漏可达的滚动历史；
  - `S_obs(t; q)`：使用真实状态，但被当前保护计划自遮蔽（受保护的步骤因 q_t 已生效而显得不敏感）；
  - `S_replay_ref(t)`：固定干预——对每条记录的状态在**相同的未保护干预 q₀** 下重放，恢复完整不可变 FP16 快照、深拷贝持久状态并匹配随机种子。
- **闭环误差分析**：外循环状态演化 `δs_{j+1} = A_j δs_j + B_j ε_j` 说明下游任务影响还取决于转移雅可比乘积，因此画像值仅用于**提出受控的调度修复**，而非估计边际任务增益。
- **调度修复**：用 `T_replay = TopK_t S_replay_ref(t)`（|T_replay|=|T_q|=K）替换受保护步骤集合，不改变精度等级或数量。

## 五、讨论与深层见解

- **“粒度”并非越细越好**：逐元素级精度分配在有限标定数据下方差过大，反而劣于层/列级决策；QuantWAMs 的经验是——在数据量可支撑的前提下选择最细粒度，否则退回到稳健的粗粒度，并用理论条件（`N⋆_c`）指导何时可以安全细化。这挑战了直觉上“混合精度=逐位宽搜索”的做法，为 PTQ 的工程实践提供了更可操作的判据。
- **PTQ 决策本质上是闭环控制问题**：对 WAMs 而言，量化误差不是一次前向的静态噪声，而是进入外循环状态演化的逐拍扰动。QuantWAMs 的固定干预重放可视为在部署前用“最接近真实部署的因果干预”估计每个时间步的敏感性，从而将校准上下文的选择从“数据采样细节”提升为“与部署因果结构对齐”的第一性原则。
- **结构先验比数据量更关键**：共享基异常值校准表明，当成员间存在坐标可容许的共享子结构时，少量标定数据即可池化出稳定掩码；而跨无共同坐标系的成员（如专家私有残差流）即使数据增加也无法安全池化。这提示 PTQ 设计应先分析模型的计算图拓扑（哪些成员共享同一量化输入坐标），再决定统计量的汇集方式。
- **与现有量化范式的理论连接**：Proposition 1 的池化交叉点推广了经典“均值估计中偏差-方差权衡”到通道统计量的两层随机效应模型；当 τ²=0（成员同质）时退化为标准池化占优结论，当 m=1 时退化为单成员最优掩码。该框架可自然延伸到其他需要跨模块/跨样本共享统计量的量化方法（如 SmoothQuant 的平滑因子、AWQ 的缩放因子）。
- **局限性与开放问题**：①理论分析基于高斯-亚高斯统计假设与对角/分块 Fisher 近似，非高斯、非平稳激活分布下的紧致性未证明；②固定干预重放的“固定干预 q₀”本身是设计选择，若部署时保护计划与标定时不一致，需重新审计；③对扩散采样步数（如 50 步 vs 20 步）的鲁棒性仅在单一默认配置下验证；④任务成功率在 LIBERO/RoboTwin 之外的真实机器人硬件上尚未验证；⑤量化感知微调（QAT）与 PTQ 的混合策略未纳入比较，可能低估端到端微调方案的竞争力。

## 六、结论

QuantWAMs 是首个面向闭环部署的世界动作模型的训练后量化框架。其核心贡献不是新的量化算子了，而是引入了**校准上下文的三维刻画**（证据汇集范围 G、状态分布 D、目标函数 L），并据此给出三个对齐策略：共享基异常值校准（对齐结构）、共同训练目标显著性（对齐目标）、固定干预滚动审计（对齐状态分布）。在 Fast-WAM 与 LingBot-VA 两个代表性 WAM 架构上、跨 RoboTwin 与 LIBERO 基准的系统实验表明，该方法在 W8A8 与 W8/16 混合精度下将成功率差距压缩到全精度模型的数个点以内，显著优于 GPTQ/AWQ/PTQ4DiT 等现有方法，并将标定数据需求降低一个数量级以上。论文在理论上给出了池化安全的充要条件与掩码恢复概率界，为后续在更大规模 WAM 上部署量化策略提供了可检验的设计准则。
